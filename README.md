# CSS Selector查询工具（CSS Selector Finder）

Chrome 开发者工具扩展。在 DevTools 面板里**提取、编辑、分析 CSS 选择器**，支持「智能缩写 / 完整路径」双向现算。

- 面板标题：`CSS Selector Finder`
- 免安装依赖：纯原生 JavaScript，无构建、无 npm
- 兄弟项目：功能完全相同的 XPath 版本见 `360-XPath-Tool`

---

## 一、安装

1. 打开 `chrome://extensions/`
2. 右上角开启 **开发者模式**
3. 点击 **加载已解压的扩展程序**，选择本项目根目录（含 `manifest.json` 的那一层）
4. 打开任意网页 → `F12` 切到 **DevTools** → 顶部选择 **CSS Selector Finder** 面板

> 改完代码后，在扩展管理页点一下「刷新」即可生效。
> XPath 版和本版可以同时安装、同时使用，互不冲突（右键菜单项文案不同）。

## 二、面板构成

```
┌────────────────────────────┬────────────────────────────┐
│ 选择器: (恢复右键) [智能]     │ 结果 (3):                   │
│ ┌────────────────────────┐ │ ┌────────────────────────┐ │
│ │ html > body > #box > a │ │ │ 链接文本1                │ │
│ │                        │ │ │ 链接文本2                │ │
│ │  ← 路径框（可编辑）      │ │ │ 链接文本3                │ │
│ └────────────────────────┘ │ │  ← 结果框（只读）          │ │
│                            │ └────────────────────────┘ │
└────────────────────────────┴────────────────────────────┘
```

| 区域 | 作用 |
|---|---|
| **路径框** | 显示 CSS 选择器，**可以直接编辑**，改完停顿 0.2 秒自动出结果 |
| **模式按钮** | 把路径框里**当前的**选择器在「智能缩写」和「完整路径」之间现算切换 |
| **结果框** | 只读，实时显示路径框选择器的求值结果 |
| **结果 (N)** | 本次选择器命中的**节点数量** |
| **恢复右键** | 右键菜单失效时点击，重新注入 |

## 三、四种用法

### 1. 右键获取（最常用）

在页面上**右键目标元素 → Get Selector**：

- 扩展自动切到 CSS Selector Finder 面板
- 路径框被**覆盖**成该元素的完整选择器（已有内容会被替换，只保留最新一条）
- 命中的节点在页面上被**红色虚线框**标出
- 结果框同步显示求值结果

### 2. 手动编辑

直接改写路径框里的选择器（支持后代空格、`>`、`+`、`~`、伪类、逗号并列等）：

- 停顿约 0.2 秒后自动求值，无需按任何键
- 选择器非法时结果框显示 `[INVALID SELECTOR]`，节点计数归 0
- 命中 0 个节点时结果框显示 `[NULL]`

> **注意**：CSS 选择器只能选中**元素**。XPath 支持的 `count(//div)`、`string(//h1)` 这类标量求值在这里用不了，
> 结果框固定显示命中元素的文本，每行一个。

### 3. 智能 / 原始 切换

点路径框右边的按钮，按钮文字表示**点击后将变成什么**：

- `智能` → 逐级降级找最短可定位的选择器：先试 `#id`，再试 `标签名`，再试 `标签名.class`，
  再试「最近的 id 祖先 + 标签」「最近的 class 祖先 + 标签」，都不行才退回完整路径。
  **每一级都校验唯一性**，不唯一就继续往下降级，所以给出的应该是能唯一定位该节点的短选择器
- `原始` → 还原成从 `html` 一路用 ` > ` 拼下来的完整路径，形如
  `html > body > div#main > ul.list:nth-child(1) > li:nth-child(3)`

> 位置用 CSS 的 `:nth-child` 语义锁定：只要父元素下还有其他子元素，即使是第一个也会输出 `:nth-child(1)`，
> 否则 `ul > li` 会同时命中所有 `li`。

> 因为是对**当前选择器现算**，所以你自己手输的选择器也能享受智能缩写，不限于右键获取的那条。

### 4. 恢复右键

如果右键菜单里找不到 **Get Selector**（比如页面重载后扩展被回收），点路径框旁的 **恢复右键** 链接重新注入。

## 五、常见问题

| 现象 | 原因与处理 |
|---|---|
| 右键没有 Get Selector | 点路径框旁的「恢复右键」；并确认 DevTools 已打开且停在本插件面板 |
| 什么都没发生时提示先打开开发者工具 | 扩展只在 DevTools 面板已注册端口后才响应右键，请先 F12 |
| 点模式按钮没反应 | 路径框里的选择器当前定位不到元素（语法非法，或没匹配到任何元素）。此时路径框保持原样，结果框会显示 `[INVALID SELECTOR]` 或 `[NULL]` |
| 智能模式给出的选择器命中多个节点 | 每一级降级都做了唯一性校验，理论上不会；若确实出现请把选择器贴出来反馈（可能是页面用了 Shadow DOM） |
| 页面高亮闪得厉害 | 已内置 0.2 秒防抖；若你改过 `panel.js` 请勿删掉 `onSelectorInput` 的防抖 |
| 控制台报 `Port not found` | MV3 的 service worker 空闲约 30 秒会被回收，属正常现象，扩展已内置 1 秒间隔自动重连 |
